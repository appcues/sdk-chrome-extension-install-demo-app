<task type="auto">
  <name>Task 2: Update service worker to handle icon clicks and inject content script</name>
  <files>service-worker.js</files>
  <action>
Update service-worker.js to:

1. Add chrome.action.onClicked listener that fires when user clicks extension icon
2. In the click handler, use chrome.scripting.executeScript to inject content-script.js into the active tab
3. After injection, send a "toggle-sidebar" message to the content script using chrome.tabs.sendMessage

The pattern:
```javascript
chrome.action.onClicked.addListener(async (tab) => {
  // First, inject the content script (if not already injected)
  try {
    await chrome.scripting.executeScript({
      target: { tabId: tab.id },
      files: ['content-script.js']
    });
  } catch (err) {
    // Script may already be injected, that's OK
    console.log('Script injection:', err.message);
  }

  // Then send toggle message
  chrome.tabs.sendMessage(tab.id, { action: 'toggle-sidebar' });
});
```

Keep the existing onInstalled and onMessage listeners. The onMessage listener can remain as a placeholder for future features.

Do NOT remove any existing code - only add the onClicked handler.
  </action>
  <verify>No syntax errors: Load extension in chrome://extensions and check for errors in service worker console</verify>
  <done>service-worker.js has chrome.action.onClicked listener that injects content script and sends toggle message</done>
