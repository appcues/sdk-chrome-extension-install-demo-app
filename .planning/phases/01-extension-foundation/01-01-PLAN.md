<task type="auto">
  <name>Task 1: Create Manifest v3 configuration</name>
  <files>manifest.json</files>
  <action>
Create manifest.json in the project root with Manifest v3 structure:

```json
{
  "manifest_version": 3,
  "name": "Sales Intelligence Demo",
  "version": "1.0.0",
  "description": "A demo Chrome extension showing a sales intelligence sidebar UI",
  "icons": {
    "16": "icons/icon-16.png",
    "48": "icons/icon-48.png",
    "128": "icons/icon-128.png"
  },
  "action": {
    "default_icon": {
      "16": "icons/icon-16.png",
      "48": "icons/icon-48.png"
    },
    "default_title": "Sales Intelligence Demo"
  },
  "background": {
    "service_worker": "service-worker.js"
  },
  "permissions": []
}
```

Key points:
- manifest_version MUST be 3 (not 2)
- Use "action" not "browser_action" (v3 change)
- Use "background.service_worker" not "background.scripts" (v3 change)
- No permissions needed yet (added in Phase 2 for content scripts)
  </action>
  <verify>File exists and contains valid JSON: `cat manifest.json | python3 -m json.tool`</verify>
  <done>manifest.json exists with manifest_version: 3, action config, and service_worker reference</done>
</task>

<task type="auto">
  <name>Task 2: Create service worker and icon placeholders</name>
  <files>service-worker.js, icons/icon-16.png, icons/icon-48.png, icons/icon-128.png</files>
  <action>
1. Create service-worker.js in project root:

```javascript
// Service worker for Sales Intelligence Demo extension
// This file runs as the extension's background process in Manifest v3

console.log('Sales Intelligence Demo: Service worker initialized');

// Listen for extension install
chrome.runtime.onInstalled.addListener((details) => {
  console.log('Extension installed:', details.reason);
});

// Placeholder for future message handling (Phase 2)
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  console.log('Message received:', message);
  return false;
});
```

2. Create icons/ directory and generate placeholder PNG icons:
   - icons/icon-16.png (16x16 pixels)
   - icons/icon-48.png (48x48 pixels)
   - icons/icon-128.png (128x128 pixels)

For placeholder icons, create simple colored squares using ImageMagick:
```bash
mkdir -p icons
convert -size 16x16 xc:#4F46E5 icons/icon-16.png
convert -size 48x48 xc:#4F46E5 icons/icon-48.png
convert -size 128x128 xc:#4F46E5 icons/icon-128.png
```

If ImageMagick not available, create minimal valid PNGs programmatically or download placeholder icons.

The color #4F46E5 is indigo-600 (professional, matches future Tailwind styling).
  </action>
  <verify>
- `ls -la service-worker.js` shows file exists
- `ls -la icons/` shows all three icon files
- `file icons/*.png` confirms they are PNG images
  </verify>
  <done>service-worker.js exists with install listener, all three icon PNGs exist in icons/ directory</done>
</task>
