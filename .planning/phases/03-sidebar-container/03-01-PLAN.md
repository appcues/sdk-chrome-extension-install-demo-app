Add CSS transition animations for sidebar open/close:

1. In the shadow DOM `<style>` element, add transition and transform properties:
```css
.sidebar {
  /* existing styles... */
  transform: translateX(100%);
  transition: transform 0.3s ease-out;
}
.sidebar.open {
  transform: translateX(0);
}
```

2. Modify showSidebar():
   - Append the host element to document.body
   - Use requestAnimationFrame or setTimeout(0) to add the 'open' class after the element is in DOM
   - This ensures the initial state (translateX(100%)) is rendered before transitioning

3. Modify hideSidebar():
   - Remove the 'open' class to trigger slide-out animation
   - Wait for transition to complete (300ms) before removing from DOM
   - Use transitionend event or setTimeout to handle removal timing

Code pattern for showSidebar:
```javascript
function showSidebar() {
  if (!hostElement) {
    hostElement = createSidebarHost();
  }
  document.body.appendChild(hostElement);
  // Trigger reflow, then add open class for animation
  requestAnimationFrame(() => {
    requestAnimationFrame(() => {
      sidebarElement.classList.add('open');
    });
  });
  sidebarVisible = true;
}
```

Code pattern for hideSidebar:
```javascript
function hideSidebar() {
  if (sidebarElement) {
    sidebarElement.classList.remove('open');
    // Wait for animation to complete before removing
    setTimeout(() => {
      if (hostElement && hostElement.parentNode) {
        hostElement.parentNode.removeChild(hostElement);
      }
      hostElement = null;
    }, 300);
  }
  sidebarVisible = false;
}
```
